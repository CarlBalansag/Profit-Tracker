# Selvora frontend

React/Vite frontend for Selvora. Run `npm ci` and `npm run dev` from this directory after configuring the API environment.

See the [root README](../README.md) for getting started and [PROJECT_CONTEXT.md](../PROJECT_CONTEXT.md) for architecture, environment variables and project contracts.

Commands: `npm test`, `npm run lint`, `npm run build`, `npm run preview`.
