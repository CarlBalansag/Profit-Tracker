# Historical feature notes

These files preserve earlier feature plans and prototypes. They are not the current knowledge base or a list of active tasks.
Some contain proposed tables, fields, formulas and integrations that were never implemented.
The calendar reference is preserved unchanged from local user data.

Start with [PROJECT_CONTEXT.md](../../PROJECT_CONTEXT.md) for current architecture and contracts, or [BACKLOG.md](../../BACKLOG.md) for future ideas.
The Prisma schema and application source take precedence over these notes.

The old todo.txt was consolidated into BACKLOG.md; Changes.txt was deleted at the user's request. Use Git history for code changes.
